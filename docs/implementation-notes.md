# Решения и границы применимости

| Требование | Решение и место реализации |
|---|---|
| Единственный snapshot | SQL и Python используют константу 2026-10-26; часы контейнера нужны только для служебных timestamp и расписания |
| Источник не повреждается | Копии исходных SQL находятся в sql/; оригиналы снаружи репозитория проверяются SHA-256 по source-hashes.json |
| Надёжная инициализация | Транзакция psql объединяет DDL, генератор и маркер; source_init проверяет маркер |
| ETL на Python | validate, категории, пакетная COPY-загрузка; чтение серверным курсором по 10 000 строк |
| Backfill | Окно по loading_date включительно; удаление и загрузка в одной транзакции, каскадное обновление связей |
| Смена состояния DQ | Исчезает прежняя валидная строка при исправлении на невалидную и наоборот; причины карантина перезаписываются |
| Нет fan-out городов | Минимальный source id на gc_id, PK в Core |
| Нет fan-out кузовов | Уникальная пара price_id/body_group, std_id; fallback только при отсутствии связей |
| price_dates | Все исходные даты сохраняются; DISTINCT в пределах календарной ячейки; cutoff до округления до месяца |
| Рыночные агрегаты | Physical table, grain protected unique index, атомарное DELETE + INSERT |
| Календарные сравнения | JOIN ровно month−1 month / month−1 year; пропуск остаётся NULL |
| Trust | HIGH для плотной свежей ячейки, свежесть измеряется от первого числа её месяца |
| No leakage | Положительный allowlist, ни сырой цены, ни производных цены, ни outlier_mark, ни price_group_stats |
| Обучение | Фиксированный train, test не участвует в подборе/early stopping, категории обучает только CatBoost на train |
| M:N для ML | Набор групп кузова — одна отсортированная категория на сделку, не несколько копий таргета |
| Повтор обучения | Content-addressed model cache в artifacts, параметры и семя зафиксированы |
| Скоринг | PK price_id, полная атомарная замена; будущие actual/errors NULL, CHECK в БД |
| ClickHouse | MergeTree, staging + EXCHANGE в Atomic database; тест всех строк и числовых показателей |
| Airflow | LocalExecutor, max_active_runs=1, retries=2, срок задачи 40 минут; @daily/catchup=False |
| Чистое окружение | Dockerfiles и Compose содержат весь runtime; локальная .venv не нужна |

## Компромиссы

Это стенд для снимка из задания, а не подключение к живому API курсов ЦБ: официальные курсы берутся из таблицы предоставленного источника. Отсутствующий курс не заполняется даже при наличии курса на другой день. Спорная редкая будущая ветка поиска курса по created_at не выполняется, поскольку nearest_rate_date уже дана источником и её NULL прямо означает карантин по README задания.

Существующий outlier_mark используется как фильтр качества исторического таргета, не как ML feature. Его возможное запаздывание 26.10.2026 ограничивает оценку качества. Гиперпараметры заданы заранее, метрики не подгоняются к референсному отчёту. Модель оценивает цену, а не интервал неопределённости.

Для будущих валидных сложных маршрутов сохраняется прогноз, но train состоит из простых маршрутов. Этот прогноз вне обучающего домена. В промышленном варианте разумно обучить отдельную модель сложных маршрутов или добавить явную маркировку применимости.

Core и Mart обновляются разными транзакциями в последовательных задачах: между ними читатель может увидеть новый Core и прежнюю завершённую Mart. Незавершённых строк внутри одной физической таблицы он не увидит. Для единого согласованного снимка всех слоёв нужен run_id/version publishing.

При переносе исходной сделки на другую loading_date обработайте оба затронутых периода или выполните полный ETL. Удаления источника выявляются при обработке прежнего окна; для CDC нужны tombstones. Справочники перечитываются целиком. Модельный хеш включает признаки, таргет и параметры; при изменении кода признаков, не меняющем значения train, следует сбросить кэш модели явно.

У стенда нет HA, продакшен TLS, secret manager, мониторинга drift или ролевого разграничения подключений к хранилищу. Установлены локальные демонстрационные учётные данные из .env.example. Superset не включён; пустой BI-сервис не разворачивается.

## Документация библиотек

При выборе runtime использованы [официальная документация Airflow Docker Compose](https://airflow.apache.org/docs/apache-airflow/2.10.3/howto/docker-compose/index.html), [CatBoostRegressor](https://catboost.ai/docs/en/concepts/python-reference_catboostregressor) и [параметры CatBoost](https://catboost.ai/docs/en/references/training-parameters/common). Версии runtime зафиксированы в Dockerfiles и requirements.txt; результаты относятся к фактически собранным образам.
